Projet Power BI Lireka

Ton accès au projet Power BI

Pour Emma Henry
Version du 30/10/2026

Les fichiers du rapport Power BI sont conservés chez Lireka, sur le serveur géré par Inforeso. Cet accès te donne une copie du projet sur ton PC et, plus tard, la possibilité de modifier et republier le rapport toi-même.

Ce que tu as à faire : quatre étapes, une seule fois, une dizaine de minutes. Pour consulter le rapport ou faire tes propres analyses, rien ne change.

1

Installer Git 5 minutes

Télécharge Git for Windows sur git-scm.com/download/win et installe-le en gardant toutes les options proposées.

2

Créer ta clé d'accès 2 minutes

Ouvre PowerShell : touche Windows, tape PowerShell, Entrée. Colle cette commande (Ctrl+V), puis Entrée :

ssh-keygen -t ed25519 -C "ehenry@lireka.com"

Trois questions s'affichent : appuie sur Entrée à chacune, sans rien taper.

Tu dois voir : Your public key has been saved in ... Si la question Overwrite (y/n)? apparaît, tu as déjà une clé : tape n, Entrée, et passe à l'étape 3.
3

M'envoyer ta clé 1 minute

Dans le même PowerShell, colle cette commande, puis Entrée. Elle copie ta clé, rien ne s'affiche :

Get-Content $env:USERPROFILE\.ssh\id_ed25519.pub | Set-Clipboard

Colle-la (Ctrl+V) dans un message Slack pour moi. Elle n'est pas secrète. N'envoie jamais rien d'autre du dossier .ssh.

Tu dois voir, dans ton message : une longue ligne qui commence par ssh-ed25519.
4

Récupérer le projet 2 minutes, après mon message

J'enregistre ta clé sur le serveur et je te préviens sur Slack. Ensuite seulement, ouvre PowerShell comme à l'étape 2, colle cette commande, puis Entrée :

git clone emma.henry@20.19.33.4:C:/git/lireka.git

Une question Are you sure you want to continue connecting s'affiche. Vérifie que les lignes au-dessus contiennent SHA256:eBMqTCmtpfbE5ym8v8/94o5zQl9i0h6ADtGQhMk4zJc, puis tape yes en entier et Entrée.

Tu dois voir : Cloning into 'lireka'..., puis quelques lignes qui finissent par done. Le projet est maintenant sur ton PC, dans C:\Users\<ton nom>\lireka.

C'est tout pour l'instant

Pendant ma mission, tu n'as rien d'autre à faire. Avant la fin, on fera ensemble une courte séance : récupérer les mises à jour, modifier le rapport et le republier.

Si un message d'erreur apparaît

Ne corrige rien. Fais une capture d'écran de PowerShell et envoie-la-moi sur Slack.
